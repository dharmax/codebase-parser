# @dharmax/codebase-parser

Universal, lightweight, and fast multi-language codebase parser. 

## Features
- **Fast Extraction**: Regex-based symbol, fact, and note (TODO/FIXME) extraction.
- **Multi-language**: Supports JS/TS, CSS/SCSS, HTML/Riot, JSON, YAML, Markdown.
- **Standardized Schema**: Consistent output across all supported languages.
